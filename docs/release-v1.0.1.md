# v1.0.1

This release has no change to the extension code. Activity still installs acclass 1.0.0.

- **npm.** The package is on npm as `@jensilo/pi-activity`. Install it with
  `pi install npm:@jensilo/pi-activity@1.0.1`. The Git install still works:
  `pi install git:github.com/jensilo/pi-activity@v1.0.1`.
- **Tests.** `npm test` now finds a managed Pi install in `~/.pi/agent` without
  `PI_GLOBAL`.
